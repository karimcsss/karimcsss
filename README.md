### ⚖️ JORT RAG — Local Question Answering on Tunisian Legal Texts

A **100% local** Retrieval-Augmented Generation system (no cloud API) over French-language documents from the *Journal Officiel de la République Tunisienne* (JORT).

| Attribute | Detail |
|-----------|--------|
| **Stack** | Ollama (`qwen2.5:1.5b`), `all-MiniLM-L6-v2`, ChromaDB, pdfplumber |
| **Hard problem solved** | Two-column PDF layouts broke text extraction; solved with dynamic gutter detection using word-position density histograms |
| **Results (honest)** | Recall@5 = **42%**, MRR = **0.417** on the indexable documents |
| **Status** | Stopped at Sprint 2. Results and limits are documented rather than hidden |

### 📈 Pair Trading — Statistical Arbitrage in Python (V2)

**In plain words:** find two companies whose stock prices move together over the long run. When the gap between them becomes unusually wide, bet that it will close.

| Attribute | Detail |
|-----------|--------|
| **Stack** | Python, yfinance, pandas, statsmodels, Pydantic, matplotlib |
| **V1** | MSFT/GOOGL tested: **not cointegrated** (p = 0.35), so the pair was rejected |
| **V2** | Screened 5 sector pairs. **Visa/Mastercard** is cointegrated (p = 0.0021, hedge ratio = 0.5402) |
| **Backtest** | 4 closed trades, 100% win rate. This is a **very small sample** and is not proof of profitability |

</td>

<summary><b>📖 Mini glossary (for non-specialists)</b></summary>
<br/>

| Term | Plain-language meaning |
|------|------------------------|
| **RAG** | An LLM that first retrieves relevant documents, then answers using them |
| **Cointegration** | Two series that wander but stay linked over the long run |
| **p-value** | The lower it is, the less likely the result is due to chance (below 0.05 is the usual threshold) |
| **Hedge ratio** | How much of one asset to trade against the other so the position stays balanced |
| **Pearson r** | Correlation between two variables, from -1 to +1 |
| **Recall@5 / MRR** | How often, and how high, the right document appears among the top search results |

</details>
